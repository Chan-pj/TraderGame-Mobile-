# 트레이더게임 (TraderGame)

턴제 주식투자 시뮬레이터 모바일 게임입니다. 가상의 종목을 사고팔아 순자산 **50,000,000원**을 만들면 은퇴(클리어)합니다.
한 판이 30~50턴 안에 끝나는 **로그라이크** 구조라서, 판마다 시장이 달라지고 판이 끝날 때마다 영구 성장 요소가 쌓입니다.

HTML/CSS/JavaScript로 만들고 [Capacitor](https://capacitorjs.com/)로 Android 앱으로 패키징했습니다. 같은 코드가 웹 브라우저에서도 동작합니다.

**▶ 웹에서 바로 플레이: https://chan-pj.github.io/TraderGame-Mobile-/**

## 주요 기능

### 매 판 달라지는 시장
- **랜덤 종목 구성**: 해금한 섹터에서 종목이 랜덤으로 상장되고, 시작 주가도 ±20% 범위에서 달라집니다.
- **시장 국면**: 상승장, 하락장, 박스권, 변동장 중 하나가 12~20턴마다 바뀝니다. 국면마다 강세 업종이 다릅니다.
- **뉴스와 출처 등급**: 뉴스는 3턴 동안 해당 종목·업종의 주가에 영향을 줍니다.

  | 출처 | 적중률 | 영향 |
  |---|---|---|
  | 공시 | 높음 | 작음 |
  | 보도 | 보통 | 보통 |
  | 루머 | 낮음 | 큼 |

- **급등 이벤트**: 테마주가 갑자기 급등합니다. 몇 턴이나 더 오를지는 알 수 없습니다.
- **상장폐지**: 주가가 시작가의 12% 이하로 떨어지면 상장폐지되고, 보유 주식은 사라집니다.

### 경영 요소
- **임대료**: 5턴마다 청구되며, 청구할 때마다 크게 늘어납니다. 사실상 시간 제한 역할을 합니다.
- **직원 영입**: 3턴째부터 8턴마다 후보 중 1명을 골라 영입합니다. 고용비는 없고 급여만 냅니다.
- **대출**: 10턴 안에 갚으면 원금만 내면 됩니다. 대신 취급 수수료가 있고, 상환한 뒤에는 한동안 다시 빌릴 수 없습니다.
- **매매 수수료**: 사고팔 때마다 0.25%가 붙습니다.

### 판과 판 사이의 성장
- **포인트**: 판이 끝나면 최고 순자산과 은퇴 여부에 따라 포인트를 받습니다.
- **성장 화면**: 포인트로 시작 자금, 새 섹터(바이오·레저·엔터), 새 직원, 영입 후보 수를 해금합니다.
- **업적**: 9종이 있고, 달성하면 포인트와 이후 모든 판에 적용되는 보너스를 줍니다.
- **플레이 기록**: 판별 결과, 난이도, 고용한 직원 등을 저장합니다.

### 난이도

| 난이도 | 시작 자금 | 변동성 | 임대료 증가 |
|---|---|---|---|
| 안정형 | 25,000,000원 | 낮음 | 보통 |
| 공격형 | 22,000,000원 | 높음 | 급증 |

## 밸런스

수치는 몬테카를로 시뮬레이션(전략별 2,500판 이상)으로 조정했습니다. 아래는 업적·성장 보너스 없이 첫 판을 할 때의 은퇴율입니다.

| 전략 | 안정형 | 공격형 |
|---|---|---|
| 뉴스만 따라가기 | 약 37% | 약 19% |
| 국면(강세 업종)만 따르기 | 약 28% | 약 7% |
| **뉴스 + 국면 섞어 쓰기** | **약 59%** | **약 28%** |
| 무작위 매매 | 약 4% | 약 2% |

한 가지 전략만으로는 깨기 어렵고, 여러 정보를 함께 판단해야 가장 잘 깨지도록 맞췄습니다. 성장 요소가 쌓이면 점점 쉬워집니다.

## 기술 스택

- **프론트엔드**: Vanilla JavaScript, HTML, CSS (프레임워크 없음)
- **앱 패키징**: Capacitor 8 (Android)
- **저장소**: 진행 중인 게임 상태, 플레이 기록, 업적, 성장 정보를 SQLite로 저장합니다.
  - Android 앱: [@capacitor-community/sqlite](https://github.com/capacitor-community/sqlite)
  - 웹 브라우저: [sql.js](https://sql.js.org/)를 쓰고, 데이터는 브라우저의 localStorage에 저장합니다. 기기와 브라우저마다 따로 저장되며, 시크릿 모드에서는 창을 닫으면 사라집니다.
- **웹 배포**: GitHub Pages (GitHub Actions로 `www/` 자동 배포)
- **Android**: minSdk 24, targetSdk 36

## 프로젝트 구조

```
TradeGame/
├── www/                     # 게임 소스 (여기를 수정)
│   ├── index.html           # 화면 구성
│   ├── script.js            # 게임 로직 전체
│   └── style.css            # 스타일
├── .github/workflows/       # GitHub Pages 자동 배포
├── android/                 # Capacitor Android 프로젝트
│   └── app/src/main/assets/public/   # www/가 복사되는 위치 (직접 수정 X)
├── capacitor.config.json
└── package.json
```

`script.js` 맨 위에 밸런스 상수가 모여 있습니다. 시작 자금, 임대료, 뉴스 출처, 시장 국면, 직원, 업적, 업그레이드 등입니다.

## 빌드 및 실행

### 준비물
- Node.js
- Android Studio (Android SDK 포함)

### 설치

```bash
npm install
```

### 웹 소스를 Android에 반영
`www/`를 수정한 뒤에는 반드시 Android 프로젝트로 복사해야 합니다.

```bash
npx cap copy android
```

플러그인을 추가하거나 바꿨다면 `copy` 대신 `sync`를 실행합니다.

```bash
npx cap sync android
```

### 실행
Android Studio로 프로젝트를 열어 에뮬레이터나 실제 기기에서 실행합니다.

```bash
npx cap open android
```

### 디버깅
에러는 화면 팝업 대신 콘솔에 기록됩니다. 기기를 USB로 연결한 뒤 PC Chrome에서 `chrome://inspect`로 접속하면 WebView 콘솔을 볼 수 있습니다.

### 웹 버전 로컬 실행
`www/` 폴더를 간단한 웹 서버로 띄우면 브라우저에서 바로 플레이할 수 있습니다. sql.js를 CDN에서 불러오므로 인터넷 연결이 필요합니다.

```bash
cd www && python -m http.server 8000
```

그다음 브라우저에서 http://localhost:8000 에 접속합니다.

### 웹 배포
`main` 브랜치에 `www/` 변경을 push하면 GitHub Actions(`.github/workflows/deploy-pages.yml`)가 자동으로 GitHub Pages에 배포합니다.
